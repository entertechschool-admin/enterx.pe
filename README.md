# enterx.pe

Sitio web público de **EnterX** — la unidad de IA aplicada B2B de Enter Tech School (respaldo CETEMIN).
Construido con Next.js + Tailwind CSS.

## Para cualquier agente implementador

Lee en orden: **`AGENTS.md`** (cómo trabajar) → **`SPEC.md`** (qué construir) →
**`CONTEXT.md`** (contenido + marca) → `brand/reference/manual-de-marca.html` (referencia visual).
`CLAUDE.md` contiene únicamente notas de compatibilidad y operación para ClaudeCode.
